Best first message

Send the system type, the devices involved, the current behavior, and the outcome you need. If the issue is payment-related, include the terminal or processor path. If it is petroleum-related, include the site layout and controller context.

What to include

Give enough detail to describe the technical problem clearly

System context

Tell us what kind of system is involved, whether it is payment, petroleum, cloud, or an embedded integration.

Device details

List the controllers, terminals, pumps, or other devices that are part of the workflow so the support path is easier to reason about.

Current behavior

Explain what is happening now, what changed, and how the issue shows up in production.

Desired outcome

Describe what successful behavior looks like so the technical path can be mapped against the business need.

Next step

WannLynx can help you move from a technical issue to a supportable plan
